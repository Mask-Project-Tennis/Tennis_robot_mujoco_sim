# exp14: V12 位置模式 PD 增益扫描

> 日期: 2026-06-22
> 状态: 待运行
> 依赖: exp13（V12 力矩 85.7% vs 位置 12-24%）

## 目的

exp13 暴露 V12 位置模式命中率仅 12-24%（力矩模式 85.7%）。根因是位置模式下
B 矩阵含 `diag(Kp)`（`B = dt * M⁻¹ * diag(Kp)`），默认 PD 增益
`kp=[200,200,200,50,50,20]` 针对力矩模式标定，位置模式梯度行为截然不同。

本实验系统扫描 Kp_base × Kd_ratio 矩阵，寻找 V12 位置模式最优 PD 组合。

## 假设

1. 位置模式需要显著更低的 Kp（~50-200 范围），因为 B 矩阵放大了 Kp 的影响
2. Kd_ratio ≈ 0.08-0.10 是阻尼最优区间（与 exp10 力矩模式结论一致）
3. 最优组合下位置模式命中率应 > 50%

## 参数矩阵

| 变量 | 值 |
|------|---|
| Kp_base | [50, 100, 150, 200, 300, 500, 750, 1000] |
| Kd_ratio | [0.05, 0.08, 0.10, 0.15] |
| Seeds/combo | 30 |
| **总 runs** | **960** |

Kd_base = Kp_base × Kd_ratio（所有 6 关节统一）。

## 固定参数

```bash
--serve-box --ball-speed 7 --position-mode --no-plot
```

## 参考

- **exp10**: V11 位置模式 PD 扫描（3360 rows, kp∈[25...2000]）
- exp10 结论: Kp_base=20, Kd_ratio=0.08 最优（针对 V11 力矩模式）

- 论文素材: 位置模式 PD 调优热力图
