# exp15: V12 力矩模式多球速鲁棒性验证

> 日期: 2026-06-22
> 状态: 待运行
> 依赖: exp13（V12 力矩模式 85.7% @ 7 m/s）

## 目的

验证 V12 在球速 5-12 m/s 全范围内的命中率稳定性，生成球速-命中率曲线
用于论文鲁棒性章节。

## 假设

1. V12 在 5-9 m/s 范围内命中率应稳定 > 70%
2. 12 m/s 高球速下命中率可能下降（挥拍行程不足）
3. 球速 vs 命中率曲线呈倒 U 型

## 参数矩阵

| 变量 | 值 |
|------|---|
| ball_speed | [7, 9, 12, 15] m/s |
| Seeds/speed | 50 |
| **总 runs** | **200** |

## 固定参数

```bash
--serve-box --no-plot  # 力矩模式（默认）
```

## 预期产出

- `results.csv`: 200 行，每行含 speed/seed/hit/pos_error/v_racket_at_hit
- `summary.txt`: 4 球速的命中率/误差/末端速度矩阵
- 论文素材: 球速-命中率曲线 + 误差分布箱线图

## 预估耗时

~10-15 分钟（200 runs × ~3s/run）
