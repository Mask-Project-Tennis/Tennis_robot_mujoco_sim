## 结果

### 命中率（有效行 n≈394/格）

| 档位 | TCP 1.8（默认） | TCP 1.0（真机限位） |
|------|-----------------|---------------------|
| full | 82.5% | **31.7%** |
| tube_only | 84.0% | **50.0%** |
| softmin_only | 82.2% | **32.5%** |
| none | 81.0% | **46.2%** |

### 层内检验（两样本比例 z 检验）

| 对比 | TCP 1.8 | TCP 1.0 |
|------|---------|---------|
| tube_only vs none | +3.05pp（p=0.26，ns） | +3.81pp（p=0.28，ns） |
| softmin_only vs none | +1.27pp（p=0.65，ns） | **−13.71pp（p<0.0001，显著有害）** |
| full vs none | +1.52pp（p=0.58，ns） | **−14.47pp（p<0.0001，显著有害）** |
| full vs softmin_only | +0.25pp（p=0.93，ns） | −0.76pp（p=0.82，ns） |

### 增益放大检验（DiD：gain@TCP1.0 − gain@TCP1.8）

| 档位 | 增益 TCP 1.8 | 增益 TCP 1.0 | DiD | p | 判定 |
|------|--------------|--------------|-----|---|------|
| tube_only | +3.05pp | +3.81pp | +0.76pp | 0.86 | ns（无放大） |
| softmin_only | +1.27pp | −13.71pp | −14.97pp | 0.0007 | **显著反向** |
| full | +1.52pp | −14.47pp | −15.99pp | 0.0003 | **显著反向** |

### 击球拍速（hit 行均值）

| 限速层 | v_racket 均值 | 说明 |
|--------|---------------|------|
| TCP 1.8 | 1.18-1.47 m/s | 各档有差异（full 1.47 > none 1.18） |

## 关键数字

| 指标 | 值 |
|------|-----|
| TCP 1.0 下 full vs none | **−14.5pp（p<0.0001）**——完整方法显著有害 |
| TCP 1.0 下 softmin_only vs none | **−13.7pp（p<0.0001）**——时间窗显著有害 |
| TCP 1.0 下 tube_only vs none | +3.8pp（ns）——走廊中性（唯一守住 50% 的档位） |
| Q5 相对版主张 | **证伪且反向**（DiD −16.0pp，p=0.0003） |
| Sanity check | TCP 1.0 full 31.7% ≈ exp16 的 36.4%；TCP 1.8 层四档全 ns 与 exp17d 一致 |
| error 行 | 48 / 3,200（1.5%，早退 seed 模式） |

## 结论

### 数据观察（Agent 生成）

1. **Q5 相对版主张证伪且反向**：「限速越紧，鲁棒层相对增益越大」不成立——软聚合组件
   （softmin、full）在 TCP 1.0 下相对点目标显著**有害**（−13.7/−14.5pp，p<0.0001），
   增益放大检验 DiD 显著反向（p<0.001）。
2. **机制解释（拍速数据支持）**：TCP 1.0 下四档拍速全被压到 ~0.87 m/s（max 1.005 =
   限位生效）；full 拍速（0.875）略高于 none（0.763）但命中率低 14.5pp——不是「更慢」，
   而是时间窗把被限速的挥拍**分散**到 ±50ms 窗口的多个候选点，点目标则把全部限速预算
   **押注**单一拦截点。对冲动作以速度余量为前提；余量被掐掉后对冲从资产变负债。
3. **走廊的「无害」地位延伸至严格限速区**：tube_only 在 TCP 1.0 下中性（+3.8pp，ns）、
   且是四档中唯一守住 50% 的档位——与「冗余但无害」结论一致，且在限速区不反转为有害。
4. **TCP 1.8 层为 7 m/s 标称复证**：四档增益全 ns，与 exp17d（7 m/s 标称四档）一致——
   7 m/s 下时间余量充裕，鲁棒层本无显著价值，与 §4.2 条件性结论自洽。
